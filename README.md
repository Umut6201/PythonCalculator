# 🧮 Python CLI Calculator

A modular and easy-to-use command-line calculator built with Python. Designed with clear object-oriented principles for simplicity, readability, and future expansion.

## 🚀 Features

- **Basic Arithmetic Operations:** Addition, subtraction, multiplication, and division.
- **Modular Structure:** Built with clean OOP architecture for easy maintenance.
- **User-Friendly Interface:** Clear menu prompts and interactive console workflow.
- **Error Handling:** Safe division operations to prevent runtime crashes (e.g., zero-division errors).

## 🛠️ Built With

* **Python 3.x**
* **PyCharm IDE**
